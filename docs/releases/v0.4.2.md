# Roomit 0.4.2

- Updates now require an explicit installation confirmation. The dialog explains
  that updating a portable EXE installs Roomit and leaves the original EXE intact.
- Choose Download latest portable EXE in the update notice, confirmation dialog,
  or Roomit menu to download without installing. Each click resolves the current
  published release and opens its versioned Windows EXE in the default browser.
- Cancel or Escape closes confirmation without downloading or installing an update.
- Native installation rejects requests without explicit installation consent.

No deletion actions. macOS device validation remains pending.

# Roomit 0.4.0

Your local AI workspace: discover your tools, follow their resources, and explore
the data they leave behind.

- English interface throughout: navigation, scan reports, resource cards,
  accessibility labels, status messages, and Roomit-generated errors.
- Live CPU, RAM, and recognized-AI GPU charts, with honest gaps for unavailable
  measurements. RAM separates used, available, system total, and installed capacity;
  choose capacity, percent, or both.
- AI desktop and CLI discovery for 19 catalog entries, including Codex, Claude
  Code, OpenCode, ZCode, Qwen, Kimi, Ollama, and LM Studio, with local brand logos.
- Interactive AI storage map and targeted scans of known AI data folders.
- Folder, single-disk, and whole-computer scans with subfolder sizes, progress,
  cancellation, exact minimum-GB filtering, and paged results without an item cap.
- Persistent exclusions and saved scans. Changes show an out-of-date notice;
  rescanning stays under your control.
- Integrated graphite/blue desktop chrome with no background terminal window.
- Signed release-based updates. Check from the Roomit menu, then choose
  **Update and restart** when a newer release is available.

Download the **Windows x64 setup** for installation and future updates, or the
standalone **Roomit-0.4.0.exe** to run directly with WebView2 installed. Updating a
standalone copy installs Roomit; launch the installed copy afterward.

No file deletion or trash actions. Scans inspect metadata without reading file
contents. Detected models, history, settings, and instructions are not automatically
classified as disposable. Discovery is catalog-based. GPU measurement is Windows
only; per-app network traffic, VRAM, and cloud GPU use are not measured. macOS
builds and device acceptance are pending. These Windows binaries have updater
signatures but no Authenticode publisher certificate.

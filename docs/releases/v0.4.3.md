# Roomit 0.4.3

- Your AI tools puts running desktop apps and CLI tools first, with a Running now
  badge and blue highlight. Tools are alphabetized within each group to avoid
  constant movement as CPU/RAM usage changes.
- Running status updates with process measurements. Paused, missing and failed
  measurements do not claim that a tool is currently running. A running process
  does not necessarily mean an active AI request.
- Open discovery details and focus are preserved when running status changes.
- Supported running tools can still appear when installation discovery fails.

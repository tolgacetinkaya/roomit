# Roomit 0.4.1

- Live resources now shows collapsible application groups with aggregate CPU,
  RAM and engine-aware GPU usage.
- Expand a group to inspect each process and its PID, CPU, RAM and GPU.
- Application and member pagination keeps large process lists manageable.
  Search and sorting operate on complete groups; group totals remain complete.
- Open groups, focused controls and member pages are preserved across live
  samples. Missing measurements remain explicit.
- Fixed the update-check message to avoid a hardcoded version label.
- Collapsing the sidebar now leaves an icon rail with accessible labels and
  hover/focus tooltips. Ctrl+B / Command+B and the saved preference still work.

No deletion actions. macOS device validation remains pending.
